L’application Android emporte une copie chiffrée de vos données pour les consulter, exporter, imprimer ou envoyer par mail avec les justificatifs. Elle se met à jour chez vous, sur le Wi-Fi de la maison.

  1. Installez Providentia sur l’ordinateur, puis l’application Android sur le téléphone.
  2. Scannez le QR code affiché sur l’ordinateur (Paramètres › Téléphone).

Vous pouvez aussi envoyer la photo ou le PDF d’un justificatif depuis le téléphone vers l’ordinateur. L’accès mobile dépend de la licence installée sur l’ordinateur.

Pour celles et ceux qui vérifient

Ce que le code fait réellement.

Chaque ligne ci-dessous a été relevée dans le code de Providentia en novembre 2026, avec sa limite. Rien n’est une promesse de plus que ce qui est écrit.

Ordinateur

La base du foyer

Le fichier opibus.db est chiffré avec SQLCipher. Sa clé, de 256 bits, est tirée au hasard au premier lancement et rangée dans opibus.storage-key, elle-même protégée par l’API Windows DPAPI. SQLCipher la reçoit sous forme de clé brute : il n’y a aucun mot de passe à deviner. Une base d’une ancienne version, encore lisible en clair, est convertie au premier lancement ; le fichier converti est relu avant de remplacer l’original.

Limite. DPAPI rattache la clé à votre compte Windows : selon la documentation de Microsoft, seul un utilisateur disposant des mêmes identifiants de connexion peut en général déchiffrer les données. Cela n’arrête pas un programme malveillant qui s’exécute sous votre propre session.

Ordinateur

Les justificatifs

Chaque PDF ou photo est écrit dans un fichier protégé par DPAPI (en-tête OPIBUS-DOC-1) ; un ancien fichier en clair est converti dès qu’il est rencontré. Les types de fichiers actifs (HTML, SVG, XML, JavaScript) ne s’affichent jamais dans l’application : ils sont proposés en téléchargement, avec une politique de sécurité qui interdit tout contenu actif.

Réseau

Le serveur local

Par défaut, Providentia n’écoute que l’adresse 127.0.0.1 : seul cet ordinateur peut lui parler. Elle ne s’ouvre au Wi-Fi de la maison (0.0.0.0) que si vous activez « Autoriser l’accès depuis le Wi-Fi de la maison » ; le réglage s’applique sans redémarrage. La création du compte, l’association des téléphones et les réglages réseau sont refusés à toute requête qui ne vient pas de l’ordinateur lui-même. Un appareil du réseau qui échoue cinq fois est mis en attente une minute, durée doublée à chaque série d’échecs, jusqu’à dix minutes.

Compte

La session

Le mot de passe du compte local est haché avec sel (fonction generate_password_hash de Werkzeug) et jamais conservé en clair. Le cookie de session est HttpOnly, SameSite=Lax, valable 30 jours. Toute écriture exige un jeton CSRF, comparé en temps constant. Les réponses portent X-Content-Type-Options: nosniff, X-Frame-Options: DENY, Referrer-Policy: no-referrer, Cross-Origin-Opener-Policy: same-origin ; l’API n’est jamais mise en cache. Le micro n’est autorisé que pour la dictée ; la caméra et la localisation sont refusées.

Téléphone

L’association par QR code

Le QR code contient l’adresse de l’ordinateur, un jeton aléatoire de 144 bits, à usage unique et valable dix minutes, et une clé de 256 bits propre à ce téléphone. Cette clé se lit sur l’écran : elle ne circule jamais sur le réseau. En échange du jeton, le téléphone reçoit un secret d’appareil de 256 bits ; l’ordinateur n’en conserve que l’empreinte SHA-256, et la compare en temps constant. La copie des données, les justificatifs et les documents envoyés par le téléphone sont chiffrés en AES-256-GCM, avec un nonce aléatoire de 96 bits et une étiquette propre à chaque usage. Le registre des téléphones (mobile.json) est lui aussi protégé par DPAPI. Un téléphone administrateur et deux téléphones de membres au plus ; la copie d’un membre est filtrée à son nom et ne contient pas le module Dépenses.

Limite. Sur le Wi-Fi, les échanges passent en HTTP simple, sans TLS. Les contenus sont chiffrés, mais l’adresse des requêtes et le secret d’appareil circulent en clair : avec ce secret, un tiers du réseau pourrait télécharger la copie chiffrée, sans pouvoir la lire faute de la clé du QR code. Activez l’accès Wi-Fi sur un réseau de confiance, et coupez-le quand vous n’en avez plus besoin.

Téléphone

Sur le téléphone

Une clé de données aléatoire de 256 bits chiffre la copie. Elle n’est jamais écrite en clair : elle est protégée par votre code à six chiffres (PBKDF2-HMAC-SHA256, 210 000 itérations, puis AES-GCM), puis enveloppée une seconde fois par une clé de l’Android Keystore ; l’empreinte digitale est facultative. Dès le cinquième code erroné, une attente de 30 secondes s’impose, doublée à chaque échec jusqu’à 15 minutes. La sauvegarde Android est désactivée pour l’application, et la fenêtre web de l’application n’ouvre ni fichiers locaux ni contenus d’autres applications.

Limite. Six chiffres, c’est un secret court. Ce qui interdit de les essayer en dehors du téléphone, c’est la seconde enveloppe du Keystore, dont les clés ne sont pas exportables ; selon la documentation d’Android, la protection par circuit matériel dépend du modèle de téléphone.

Internet

Les connexions sortantes

Quatre situations, toutes déclenchées par votre saisie ou votre clic :

  • vous saisissez un code postal à cinq chiffres dans une fiche : la commune est cherchée sur l’API publique geo.api.gouv.fr, qui reçoit ce code postal (et, comme tout site, l’adresse IP de votre connexion) ;
  • vous ouvrez le guide intégré : deux polices (Inter et Nunito) sont demandées à Google Fonts ;
  • vous activez la dictée vocale : le modèle de reconnaissance (environ 41 Mo) est téléchargé une fois depuis alphacephei.com ; la transcription se fait ensuite sur l’ordinateur ;
  • vous cliquez sur un lien vers un site officiel (service-public.fr, Légifrance…) : il s’ouvre dans votre navigateur.

Pas de statistiques d’usage, pas de rapport d’erreurs envoyé à l’éditeur, pas de compte en ligne.

Limites

Ce que Providentia ne prétend pas faire.

  • Protéger d’un programme malveillant déjà présent sous votre session Windows : DPAPI protège des autres comptes et du disque emporté seul, pas d’un logiciel qui tourne sous votre identité.
  • Chiffrer le Wi-Fi à votre place : l’accès depuis le téléphone utilise HTTP ; seuls les contenus sont chiffrés.
  • Reconnaître tous les noms dans le masquage : il s’appuie sur les noms saisis dans Providentia et sur des règles (titres de civilité, formats d’IBAN, de téléphone, de courriel…). Un nom écrit sans titre et inconnu du logiciel peut passer ; l’aperçu est là pour votre relecture.
  • Remplacer un code solide sur le téléphone : un code à six chiffres reste court.
Vérifier soi-même

Trois contrôles à la portée de tous.

  1. La base est illisible. Ouvrez %LOCALAPPDATA%\Providentia\data\opibus.db dans un éditeur hexadécimal : le fichier ne commence pas par « SQLite format 3 », l’en-tête d’une base non chiffrée.
  2. Le serveur ne sort pas de l’ordinateur. Wi-Fi désactivé dans Providentia, lancez netstat -ano | findstr LISTENING : le port de Providentia est lié à 127.0.0.1, non à 0.0.0.0.
  3. Le programme est celui publié. Comparez l’empreinte SHA-256 du fichier d’installation à celle de la page Télécharger.

Questions

Ce qu’on nous demande souvent.

C’est vraiment gratuit ?

Oui : la distribution est gratuite sous licence d’utilisation. La gratuité n’emporte aucune cession des droits sur le logiciel.

Pourquoi faut-il demander une licence ?

Chaque licence est établie pour un ordinateur précis. Cela permet à l’éditeur de garder le contrôle de la diffusion pendant la phase de test. Le message de demande est préparé par l’application.

Pourquoi Windows affiche-t-il un avertissement ?

Windows se méfie des programmes récents et peu téléchargés. Selon Microsoft, la réputation d’un fichier se construit avec le nombre de téléchargements sans incident, ce qui peut prendre plusieurs semaines. Vous pouvez vérifier l’empreinte du fichier ci-dessus.

Plusieurs personnes du foyer peuvent-elles s’en servir ?

Un compte local correspond à un foyer, qui peut compter plusieurs membres. L’accès mobile pour plusieurs téléphones est en préparation.

Où sont mes données ?

Sur votre ordinateur, dans un dossier Providentia.

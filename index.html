Sur téléphone

Votre foyer en poche, en lecture.

L’application Android emporte une copie chiffrée de vos données pour les consulter, exporter, imprimer ou envoyer par mail avec les justificatifs. Elle se met à jour chez vous, sur le Wi-Fi de la maison.

  • ✓Association en scannant un QR code affiché sur l’ordinateur
  • ✓Code à six chiffres, empreinte digitale possible
  • ✓Photo ou PDF d’un justificatif envoyé depuis le téléphone vers l’ordinateur

L’accès mobile dépend de la licence installée sur l’ordinateur.

Étape 1 · sur votre ordinateur

🖥️ Windows

Télécharger l’installateur

Version 143.5 · 44 Mo

  1. Téléchargez puis ouvrez le fichier d’installation.
  2. Si Windows affiche un avertissement (« Windows a protégé votre ordinateur »), choisissez Informations complémentaires, puis Exécuter quand même. Le programme est récent et encore peu téléchargé ; l’intitulé exact peut varier selon la version de Windows.
  3. Au premier lancement, Providentia affiche le code de votre ordinateur et prépare le message pour demander votre licence.
  4. Collez la licence reçue ou choisissez son fichier : l’application s’ouvre.

Étape 2 · sur votre téléphone

📱 Android

Télécharger l’application

Version 1.5.16

À faire après l’étape 1. La copie Android se relie à Providentia installée sur votre ordinateur : sans elle, l’application mobile ne s’ouvre pas.

  1. Téléchargez le fichier depuis votre téléphone.
  2. Autorisez l’installation quand Android le demande pour votre navigateur (« installer des applications inconnues »), puis confirmez.
  3. Sur l’ordinateur : Paramètres › Téléphone, affichez le QR code.
  4. Sur le téléphone : créez votre code à six chiffres et scannez le QR code.

Android réclame cette autorisation pour toute application qui ne vient pas de Google Play.

Questions

Ce qu’on nous demande souvent.

C’est vraiment gratuit ?

Oui : la distribution est gratuite sous licence d’utilisation. La gratuité n’emporte aucune cession des droits sur le logiciel.

Pourquoi faut-il demander une licence ?

Chaque licence est établie pour un ordinateur précis. Cela permet à l’éditeur de garder le contrôle de la diffusion pendant la phase de test. Le message de demande est préparé par l’application.

Pourquoi Windows affiche-t-il un avertissement ?

Windows se méfie des programmes récents et peu téléchargés. Selon Microsoft, la réputation d’un fichier se construit avec le nombre de téléchargements sans incident, ce qui peut prendre plusieurs semaines. Vous pouvez vérifier l’empreinte du fichier ci-dessus.

Plusieurs personnes du foyer peuvent-elles s’en servir ?

Un compte local correspond à un foyer, qui peut compter plusieurs membres. L’accès mobile pour plusieurs téléphones est en préparation.

Où sont mes données ?

Sur votre ordinateur, dans un dossier Providentia.
